# HH Auto Extension - Описание ветки main

## Общая информация

Расширение для браузера Brave (Chromium) для автоматических откликов на hh.ru.
- **Манифест:** Manifest V3
- **Архитектура:** Service Worker (background script)
- **Запуск:** Клик по иконке расширения
- **Домен:** vidnoe.hh.ru

## Файлы проекта

```
background.js      - основной скрипт (service worker)
manifest.json      - манифест расширения
README_main.md     - этот файл
```

## Алгоритм работы

### 1. Проверка авторизации
- Проверяет наличие элемента `data-qa="mainmenu_profileAndResumes"`
- Если не залогинен — остановка

### 2. Переходы по страницам
- Переход на `vidnoe.hh.ru`
- Переход на список резюме `/applicant/resumes`
- Получение списка всех резюме пользователя

### 3. Обработка каждого резюме
Для каждого резюме из списка:
- Открывает страницу резюме
- Находит ссылку на подходящие вакансии
- Переходит на страницу вакансий

### 4. Обработка вакансий
Для каждой вакансии (макс. 15):
- Пропускает вакансии с ключевыми словами "разработчик", "реклам"
- Определяет нужное резюме по правилу ПВР1
- Создаёт вкладку с вакансией (в фоне)
- Нажимает кнопку "Откликнуться"

### 5. Работа с модальным окном (МОР1)
Определяет тип модального окна:
- **simple1:** есть кнопка "Добавить сопроводительное", кнопка "Откликнуться" активна
- **simple2:** textarea уже открыт, кнопка "Откликнуться" неактивна

Для simple1:
- Выбирает резюме из выпадающего списка (карточки)
- Нажимает "Добавить сопроводительное"
- Вставляет текст письма
- Нажимает "Откликнуться"

Для simple2:
- Вставляет текст в уже открытое поле
- Нажимает "Откликнуться"

### 6. Закрытие вкладок
- После отправки отклика ждёт 12 секунд и закрывает вкладку
- При ошибках закрывает вкладку сразу

## Правило выбора резюме (ПВР1)

| Условие в названии вакансии | Выбранное резюме |
|----------------------------|------------------|
| "отдела" | Руководитель отдела |
| "руководитель направления", "деливери", "delivery", "релиз" | Руководитель направления |
| "аналитик", "системн", "анализа" | Аналитик |
| "проект", "менеджер", "руководитель проект", "project manager" | Руководитель проектов |
| всё остальное | Руководитель направления |

## Конфигурация (CONFIG)

```javascript
{
  minDelay: 2000,              // мин. случайная задержка (мс)
  maxDelay: 4000,              // макс. случайная задержка (мс)
  maxVacancies: 15,            // макс. вакансий для обработки
  doneDelay: 12000,            // задержка после отправки отклика (мс)
  excludeKeywords: ['разработчик', 'реклам'],  // пропускать вакансии
  coverLetter: "..."           // текст сопроводительного письма
}
```

## Логирование

Все действия выводятся в консоль браузера (F12 → Console):
- `=НАЧАЛО=. был клик по иконке` — запуск
- `=== Обработка резюме N/M: <название> ===`
- `Обрабатываю вакансию N/15: <название>`
- `Тип модального окна: simple1/simple2`
- `Отправляю отклик`
- `=== Работа завершена ===`

## Типы модальных окон

### simple1
- Кнопка "Добавить сопроводительное" присутствует
- Кнопка "Откликнуться" активна
- Нет дополнительных полей ввода

### simple2
- Textarea уже открыт
- Кнопка "Добавить сопроводительное" отсутствует
- Кнопка "Откликнуться" неактивна (disabled)
- В textarea дефолтный текст "Сопроводительное письмо"

## Ошибки и обработка

| Ситуация | Действие |
|----------|----------|
| Кнопка "Откликнуться" не найдена | Закрыть вкладку, следующая вакансия |
| Модальное окно не определено | Закрыть вкладку, следующая вакансия |
| Дополнительные вопросы | Закрыть вкладку, следующая вакансия |
| Тип модального окна не определён | Закрыть вкладку, следующая вакансия |
| Поле письма не найдено | Закрыть вкладку, следующая вакансия |

## Установка

1. Открыть `chrome://extensions/`
2. Включить "Режим разработчика"
3. "Загрузить распакованное расширение"
4. Выбрать папку с проектом
5. Кликнуть по иконке расширения для запуска

## Особенности реализации

- Использует `chrome.scripting.executeScript()` для инжекции кода во вкладки
- Слушатель `chrome.runtime.onMessage` получает сообщения от инжектированных скриптов
- Вкладки создаются с `active: false` (в фоне)
- Скроллинг списка резюме для загрузки всех элементов
- Уникальность резюме определяется по названию (Set)
