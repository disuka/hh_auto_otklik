## Логирование
В случае, если сервис логирования не вернул ответ 201, то нужно остановить работу расширения
Инструкция по логированию через HTTP API

1. Отправляйте POST-запросы на эндпоинт
URL: http://localhost:8000/api/v1/logs - нужно вынести в настройку
Метод: POST
Заголовки:

Content-Type: application/json
X-API-Key: secret-key-for-hh-browser - нужно вынести в настройку

Тело запроса (JSON):

json
{
  "project": "my-bot", - значение в настройку
  "level": "info",
  "message": "Событие",
  "timestamp": "2025-05-03T10:00:00Z",
  "metadata": {"anything": "value"}
}
level может быть: debug, info, warn, error.
metadata — любой JSON объект (опционально).

2. Что важно знать
Сервис асинхронный, не блокирует ваш код.
Все логи хранятся в PostgreSQL, схема disa_logger_sh, таблица t_disa_logs.
Можно слать много запросов — нагрузка умеренная.
Для проверки работоспособности сервиса используйте GET /health (не требует ключа).

## Д5
дождаться полной загрузки текущей страницы
Общая цель
Извлечь из каждой карточки резюме ([data-qa="resume"]) пять полей:
title (строка)
resurl (строка)
salary (целое число)

views2 (целое число)

Поиск элементов
1. Название (без изменений)
Внутри карточки найти [data-qa="resume-title"], а в нём [data-qa="cell-text-content"].
Взять textContent.trim().

2. Доход
Найти [data-qa="title-description"] [data-qa="cell-text-content"].
Получить текст. Если он начинается с «Уровень дохода не указан»:
		salaryText = "Уровень дохода не указан"
		salary = 0
	Иначе с помощью регулярного выражения найти группу цифр и пробелов перед знаком рубля: ([\d\s]+)\s*₽. Извлечённую строку очистить от пробелов. Преобразовать в число для salary.

3. Просмотры 
Найти ссылку a[data-qa="count-new-views"].
Внутри неё найти элемент, чей атрибут class содержит подстроку "count--" (использовать селектор [class*="count--"]). Это контейнер с числами.
Внутри этого контейнера найти два элемента (если есть):
Основное значение: элемент, у которого class содержит подстроку "magritte-text_style-accent" (селектор [class*="magritte-text_style-accent"]).
Прирост: элемент, у которого class содержит подстроку "magritte-text_style-positive" (селектор [class*="magritte-text_style-positive"]).
Если элемент с magritte-text_style-accent содержит текст "–" → views1 = 0, views2 = 0.
Иначе:
Из magritte-text_style-accent извлечь целое число, удалив пробелы → views1.
Если найден magritte-text_style-positive, извлечь из него целое число, удалив все символы, кроме цифр (если там будет " + 86", останется "86") → views2.
Если элемент magritte-text_style-positive не найден → views2 = 0.

4. Ссылки

Важные примечания
Селекторы по классам обязательно делать через [class*="..."] из-за динамических суффиксов в React-приложении.
Все операции выполняются после полной загрузки страницы.
Для извлечения чисел используй parseInt и replace с регулярными выражениями /\s/g (удаление пробелов) и /[^\d]/g (удаление любых нецифровых символов).
