### Базовая структура расширения:
1. **manifest.json** - главный файл с метаданными
2. **HTML/CSS/JS** - файлы интерфейса и логики
3. **Иконки** - изображения для кнопки расширения

### Пример простого расширения (Chrome):

1. Создайте папку для проекта, например `my-extension`

2. Файл `manifest.json`:
```json
{
  "manifest_version": 3,
  "name": "Мое первое расширение",
  "version": "1.0",
  "description": "Пример простого расширения",
  "icons": {
    "16": "icon16.png",
    "48": "icon48.png",
    "128": "icon128.png"
  },
  "action": {
    "default_popup": "popup.html",
    "default_icon": "icon.png"
  },
  "permissions": []
}
```

3. Файл `popup.html`:
```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { width: 200px; padding: 10px; }
    button { margin-top: 10px; }
  </style>
</head>
<body>
  <h3>Мое расширение</h3>
  <button id="myButton">Нажми меня</button>
  
  <script src="popup.js"></script>
</body>
</html>
```

4. Файл `popup.js`:
```javascript
document.getElementById('myButton').addEventListener('click', () => {
  alert('Кнопка нажата!');
});
```

### Как установить расширение в Chrome:
1. Откройте `chrome://extensions/`
2. Включите режим разработчика
3. Нажмите "Загрузить распакованное расширение" и выберите вашу папку

### Что вы хотите, чтобы делало ваше расширение?
Расширения могут:
- Изменять содержимое страниц (content scripts)
- Показывать popup при клике на иконку
- Работать в фоновом режиме (service workers в Manifest v3)
- Взаимодействовать с браузерными API (вкладками, историей, закладками и т.д.)
- Делать HTTP-запросы к API
